# Getting Started

NanoBox runs on the [BoxLang](https://boxlang.io) JVM runtime. This section
walks through installing it, running your first chat, and configuring
providers.

## Prerequisites

| Requirement | Notes |
|---|---|
| Java 21 | Required by the BoxLang runtime |
| BoxLang | Auto-installed by `install.sh` if not already present |
| BoxLang modules | `bx-ai`, `bx-sqlite`, `testbox` -- auto-installed by `install.sh` |

## Getting Started tutorial

Work through the three lessons below in order -- your progress is tracked
in your browser as you go.
